# Social Scorecard: public dashboard

Live at https://pmartbrown.github.io/social-metrics-site/. This site is **public and discoverable**.

This repo holds **no site data**. `.github/workflows/deploy.yml` deploys the dashboard to GitHub Pages as a build artifact: built files come from a private build repo and are never committed here. Until real data is connected, it deploys the made-up SAMPLE preview in `sample/`.
